# Organizzare le sezioni

Il menu laterale non si scrive a mano: **è la struttura della cartella `docs/`**.
Crei una sottocartella, dentro ci metti dei `.md`, e nel menu compare una
categoria con le sue pagine.

## Come si traduce una cartella in menu

```text
docs/
├── intro.md                    -> Introduzione
├── guida/
│   ├── _category_.json         -> etichetta e posizione della categoria
│   ├── installazione.md        -> Installazione e avvio
│   └── scrivere-una-pagina.md  -> Scrivere una pagina
└── sintassi/
    ├── _category_.json
    └── base.md
```

## Il file `_category_.json`

Sta dentro la cartella e ne descrive la voce di menu:

```json
{
  "label": "Guida rapida",
  "position": 2,
  "collapsed": false,
  "link": {
    "type": "generated-index",
    "title": "Guida rapida",
    "description": "Come avviare il sito e scrivere le pagine."
  }
}
```

| Chiave | Effetto |
| --- | --- |
| `label` | Nome della categoria nel menu |
| `position` | Ordine rispetto alle altre categorie |
| `collapsed` | `false` la mostra sempre aperta |
| `link.type` | `generated-index` crea una pagina indice automatica; togli `link` per una categoria non cliccabile |

## Decidere l'ordine

Due leve, si usano insieme:

- `sidebar_position` nel frontmatter delle **pagine**;
- `position` nel `_category_.json` delle **cartelle**.

Numera a passi di 1 partendo da 1. Se prevedi molti inserimenti futuri, numera
di 10 in 10 (`10`, `20`, `30`): infilare una pagina in mezzo non ti costringerà
a rinumerare tutto.

Senza numeri, Docusaurus ordina in modo alfabetico. Non è sbagliato, ma
raramente è l'ordine con cui vuoi che la documentazione venga letta.

## Quanto in profondita annidare

Due livelli (`docs/sezione/pagina.md`) coprono quasi tutti i casi. Al terzo
livello il menu diventa difficile da leggere: è il segnale che quella
sottosezione merita una sezione propria, o che alcune pagine vanno unite.

## Passare al menu scritto a mano

Se un giorno l'ordine automatico non basta, apri `sidebars.js` e sostituisci il
blocco `autogenerated` con l'elenco esplicito delle pagine. Nel file trovi già
un esempio commentato. Da quel momento però ogni pagina nuova va aggiunta a
mano: fallo solo quando serve davvero.
